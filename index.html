Version de démonstration, sans données. La BDD Membres est volontairement vide : cette page est publique, elle ne porte donc aucun nom ni aucune donnée de portefeuille.

Mode autonome. Pas de compte, pas d'état partagé : ce qui est saisi ici reste dans le navigateur du poste, et disparaît si les données du site sont effacées.

Pour l'équipe, les comptes et le fichier de données partagé entre postes, utilisez le kit local (Lancer_PPM.bat + _ppm_save_server.py) décrit dans le README.

🖥️ Version de travail

La version utilisée par l'équipe — avec la BDD Membres renseignée — n'est pas publiée. Elle se trouve dans le dossier outputs/ du dépôt.

Déposez ses cinq fichiers dans un même répertoire, puis double-cliquez sur Lancer_PPM.bat. Le serveur local donne à l'application un compte protégé et un fichier _ppm_state.json partagé entre postes.
