Même application, exactement. Cette page porte la même version que celle du poste de travail — même code, même numéro de version en pied de page, mêmes évolutions. Seules les données diffèrent, et la fabrication le vérifie à chaque publication en comparant l'empreinte du code des deux fichiers.

Les données affichées ici sont fictives. Projets, membres, budgets, sociétés et le site « Bellefontaine » sont inventés. Cette page est publique : elle ne porte, et ne portera, aucune donnée réelle — chaque onglet le rappelle en pied de page.

Pour travailler sur vos propres données : ⇄ Données → Importer JSON, et choisissez votre _ppm_state.json. Le fichier est lu par votre navigateur et n'est envoyé nulle part — rien n'est téléversé, rien n'est publié. Vos données restent sur ce poste, dans ce navigateur, et se rechargent à la visite suivante.

Si le fichier est chiffré, exportez-le d'abord en clair depuis son dossier : py -3 _ppm_save_server.py --export-state. Sur un poste partagé, posez le verrou (⇄ Données → 🔒 Sécurité) ou effacez les données du site en partant.

Pas de compte, pas d'état partagé ici. Pour l'équipe et le fichier de données commun, c'est le kit local : Lancer_PPM.bat + _ppm_save_server.py.

🖥️ Version de travail

La version utilisée par l'équipe — avec la BDD Membres renseignée — n'est pas publiée. Elle se trouve dans le dossier outputs/ du dépôt.

Déposez ses cinq fichiers dans un même répertoire, puis double-cliquez sur Lancer_PPM.bat. Le serveur local donne à l'application un compte protégé et un fichier _ppm_state.json partagé entre postes.
